# 🔐 Secure Password Generator

A simple and secure Python application that generates customizable random passwords containing letters, numbers, and symbols.

## 📌 Internship Task

**Task 1 – Easy: Password Generator**

Develop a Python application that generates secure and customizable passwords.

## ✨ Features

- Generate random passwords
- Custom password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes symbols
- Generate multiple passwords
- Input validation
- Uses Python's `secrets` module for secure random generation

## 🛠️ Technologies Used

- Python 3
- secrets
- string
